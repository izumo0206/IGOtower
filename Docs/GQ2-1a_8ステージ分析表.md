# GQ2-1a｜既存8ステージの「解くための考え方」分析表

## 前提

- 対象は `Assets/Resources/Stage/map1.txt`〜`map8.txt` の現行データ。
- マップ、敵のHP・攻撃力、味方のコスト・能力、ターン処理を照合し、実際に成立する代表的な手順をもとに記述した。ここで示すのは唯一解ではなく、「何に気づくと解法を組み立てられるか」である。
- 「配置時に働く能力」と「ターン終了時に働き、その後も残る能力」を区別している。敵は盤外・穴を塞がった辺として扱うため、有効マス側がすべて埋まると囲まれて倒れる。

| 2 | 2体を均等に削るのではなく、HPが低く攻撃力5の敵を継続攻撃で先に倒し、被ダメージを早く減らすことが重要になる。その後もう一方へ火力を移す考え方は、敵ごとの脅威と「あと何回攻撃されるか」を比べる場面で再利用できる。 |

| 4 | まず少ない手数で倒せる高攻撃力の敵とHP1の敵を処理し、残る高HPの敵は攻撃力を下げてから継続攻撃で安全に削るとよい。「危険度の高い敵を即処理し、長期戦になる相手だけ無力化する」という役割分けは再利用できる。 |

## 暫定的に共通する考え方

1. **継続効果は早く置き、働く回数で価値を考える。** ステージ1・2・3・5・6・7では、同じコストでもターン終了時攻撃を早く置くほど総ダメージが増える。
2. **撃破順は敵の攻撃力と倒しやすさから決める。** ステージ2・3・4・7では、高攻撃力の敵を早く減らすことが、そのまま生存可能なターン数を増やす。
3. **1回の配置に複数の仕事を持たせる。** ステージ5では複数体への継続攻撃、ステージ6では押し込みと既設火力の再利用、ステージ8では攻撃・囲み・地形利用を重ねることで手数を圧縮できる。
4. **盤面と敵位置は固定条件ではなく、解法の資源として読む。** 射程が重なる場所、移動後に囲める場所、盤外や穴が囲みの一辺になる場所を探す考え方が、特にステージ6・8で有効になる。

## GQ2-2へ渡す観察メモ

- 「継続効果の先行投資」「脅威順の撃破」「1配置の多目的化」「位置変更と地形による囲み」は、現時点で解法原理の候補になりそう。
- ただし、ステージ2・3・7は近い考え方を別配置・別数値で反復している可能性がある。次工程では、これらを同一原理の反復と見るか、数値比較・空間比較・時間比較に分けるかを検討する。
- 今回は代表解を基準にしたため、別解の数や最短手数までは分類していない。体系化の際に「必須の気づき」と「有力だが代替可能な気づき」を分ける余地がある。
