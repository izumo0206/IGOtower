## 代表手順

座標は左からa～e、画面上端から1～5。A・K・Oの矢印は攻撃方向。B・C・Fは方向不問。括弧内は反撃後HP、最終手はクリア時HP。

| マップ | 配置手順 |
|---|---|
| map7 | c3:B(3) → d2:B(1) → b2:A↓(1) |
| map8 | c1:A→(5) → a3:K→(2) → c2:A↓(1) → d3:A↓(1) |
| map9 | c2:A↑(2) → b3:C(1) → d3:F(2) → c4:A↓(2) |
| map10 | d3:O↓(10) → c4:O→(7) → b1:A↓(4) → a2:A→(1) → c2:A←(1) |
| map11 | c2:A→(6) → b3:A↓(2) → b1:C(1) → a2:C(2) → d3:A↓(2) |
| map12 | c1:A↓(4) → c3:B(1) → b1:A↓(1) |

map12のc3は初期状態で敵に四方を囲まれ、直接配置できない。上側の敵を先に倒すと配置可能になる。

## 学習意図の確認

- 探索モデル上、map7はBなし、map8はKなし、map9はFなし、map10はOなしではクリア不可。
- map14はF・Oのいずれを除外してもクリア不可。
- map13はKなしではクリア不可だが、上記のとおりBなしでもクリア可能。「BとKの両方を使う」は強制されていない。CSVから無断で数値・配置を変えず、設計上の確認事項として残す。
- map15はB・F・K・Oの全新駒を含む代表解が成立する。全新駒の使用が必須かどうかの証明はしていない。

## 検証と限界

- `Tools/verify_value_maps.py --csv "元CSVのパス"` で、保存済み9枚とCSVのHP・コスト・敵配置・使用駒の一致、および駒Oの指定値を確認した。
- A/B/C/F/K/Oの配置時能力、回復上限なし、四方の配置禁止、攻撃後の囲み判定、敵の反撃を含むモデルで全9枚の解を取得。各配置で敵が受けるダメージと囲み、その後の反撃を計算している。すべて有効タイルの盤面を対象とする。
- 探索は時間制限到達時にUNKNOWNを返す。今回の代表解と上記の駒除外検証は制限内で完了した。唯一解・最短解の証明ではない。
- 新規アセットのGUID重複なし、スクリプト・プレハブ・画像へのGUID参照先が存在することを確認した。
- Unity同梱参照ライブラリを使ったゲーム本体とEditor検証コードのコンパイル成功。エラー0、Inspector設定フィールド等のCS0649警告26件。
- Unityバッチ起動はEditorライセンス未認証で停止。Resourcesの実ロード・画面操作・描画・演出・リトライは未確認。
- Unityメニュー `Tools > IGOtower > Validate Learning Maps` の検証範囲をmap1～15と駒Oまで拡張した。ライセンスが有効な環境で実行できる。
